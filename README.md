E-Commerce Inventory Management System

About

A MySQL-based project designed to manage products, categories, customers, orders, and inventory efficiently.

Features

- Product and category management
- Customer details management
- Order tracking
- Stock availability monitoring
- Sales reports

Technologies Used

- MySQL 8.0
- MySQL Workbench
- SQL

SQL Concepts

CREATE, INSERT, SELECT, JOIN, WHERE, GROUP BY, ORDER BY and Aggregate Functions.

Objective

To develop practical SQL and database management skills through a real-world e-commerce project.
